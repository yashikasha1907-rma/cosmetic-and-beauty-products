# cosmetic-and-beauty-products
💗 Glow & Co. – Cosmetics & Beauty Products Website

Welcome to Glow & Co., a modern and stylish cosmetics and beauty products website. This project showcases a collection of skincare, makeup, and haircare products through a beautiful and user-friendly interface.

🌸 About the Project

Glow & Co. is a front-end e-commerce website designed to make exploring beauty products simple and enjoyable. It features an elegant design, attractive product cards, and interactive shopping elements.

✨ Features

- 🧴 Skincare, makeup, and haircare product collections
- 🔍 Search functionality to find products
- 🛍️ Add-to-bag functionality
- 🏷️ Category-based product filtering
- 💄 Attractive product cards with prices
- 📱 Responsive design for mobile and desktop
- 💌 Newsletter subscription section
- 🎨 Modern pastel pink and beige theme

🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive layout
- JavaScript – Interactive features and functionality

🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in your web browser.
4. Explore the Glow & Co. website!
